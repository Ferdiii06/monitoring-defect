📖 Manual Book:
Dashboard Monitoring Defect QA

Dokumen ini merupakan panduan lengkap penggunaan aplikasi Dashboard Monitoring Defect QA PT JAI. Aplikasi ini dirancang untuk memantau, mendata, dan mengelola pelaporan kecacatan produk (defect) di area produksi (Pre Assy & Final Assy) secara real-time.

1. Pendahuluan

Aplikasi ini memiliki 2 platform yang saling terhubung:

  1. Aplikasi Mobile (Android/Flutter): Digunakan oleh Quality Inspector di lapangan untuk memindai/melaporkan defect secara cepat.
  2. Dashboard Web: Digunakan oleh Administrator (SPV/Manager) untuk melihat rekapitulasi data, mengekspor laporan, serta oleh Operator untuk melakukan input/edit laporan secara manual jika diperlukan.

Terdapat 2 tingkat hak akses (role) pada versi Web:

  • Administrator: Memiliki akses penuh ke semua laporan, statistik live, dan manajemen akun.
  • Operator (User): Memiliki akses untuk menginput defect baru secara manual dan melihat riwayat laporannya sendiri.

2. Cara Akses & Login

  1. Buka browser (Google Chrome, Mozilla Firefox, dll).
  2. Masukkan alamat URL (atau IP Address) dari server aplikasi.
  3. Anda akan diarahkan ke halaman Login.
  4. Login sebagai Administrator:
    • Pilih tab atau masukkan kredensial Admin (Username & Password).
    • Klik tombol Login. Anda akan otomatis masuk ke halaman Dashboard.
  5. Login sebagai Operator:
    • Masukkan Nama yang sudah terdaftar.
    • Masukkan PIN.
    • Pilih Shift yang sedang berjalan (Shift A / Shift B).
    • Klik Login. Anda akan masuk ke halaman Operator Home.

3. Panduan Administrator

Sebagai Administrator, Anda memiliki kendali penuh terhadap monitoring data. Navigasi terletak di menu sidebar atau header.

A. Dashboard Utama

Halaman pertama setelah login. Fitur yang tersedia:

  • Statistik Cepat: Menampilkan total defect keseluruhan, jumlah defect hari ini, dan jumlah Active Users (pengguna aplikasi mobile/web yang sedang aktif).
  • Grafik/Ringkasan: Visualisasi data untuk melihat tren defect secara garis besar.

B. Laporan Area Produksi

  1. Laporan Final Assy: Menampilkan tabel rincian seluruh pelaporan defect dari jalur (line) Final Assy.
  2. Laporan Pre Assy: Menampilkan tabel rincian pelaporan defect dari jalur Pre Assy.
  3. Recent Defects: Menampilkan tabel semua laporan defect terbaru dari seluruh area, sangat berguna untuk pemantauan real-time.
TIP - Live Update: Halaman-halaman laporan di atas sudah dilengkapi fitur live polling. Jika ada laporan masuk dari aplikasi mobile, tabel akan otomatis diperbarui tanpa Anda perlu me-refresh (F5) halaman.

C. Ekspor Laporan (Download Excel)

Pada setiap halaman laporan (Final Assy, Pre Assy, Recent Defects), terdapat tombol Export.

  • Klik tombol tersebut untuk mengunduh tabel yang sedang Anda lihat ke format file Excel (.xlsx). Sangat berguna untuk diolah kembali atau untuk pelaporan rapat.

D. Edit Data Laporan (Admin)

Jika ada kesalahan input dari operator, Admin dapat mengubah data:

  1. Buka tabel laporan terkait (misalnya Recent Defects).
  2. Temukan data yang salah, klik tombol Edit (ikon pensil/edit).
  3. Ubah rincian (misal: jumlah defect, area, dsb), lalu klik Simpan.

E. Manajemen Akun (Add Account)

Untuk mendaftarkan pegawai baru ke dalam sistem:

  1. Buka menu Add Account.
  2. Masukkan rincian akun baru:
    • Nama / Username
    • Role: Pilih apakah sebagai Administrator atau User (Operator).
    • Password / PIN: Masukkan PIN untuk login operator.
  3. Klik Simpan. Akun langsung bisa digunakan.

F. Log System (Audit Trail)

Setiap kali ada laporan baru, atau data yang diedit/dihapus, sistem akan mencatatnya.

  1. Buka menu Log System.
  2. Anda dapat melihat riwayat seperti: "Budi melaporkan defect Final Assy - Line 1 - Jumlah 2", beserta waktu dan alamat IP-nya.

4. Panduan Operator (User)

Operator difokuskan pada pengisian dan pemeliharaan data defect mereka sendiri.

A. Halaman Utama (Operator Home)

Setelah login dengan Nama, PIN, dan Shift, Anda akan melihat halaman selamat datang.

  • Terdapat daftar history laporan (Recent Defects) yang pernah Anda buat pada sesi/shift tersebut.

B. Input Defect Manual

Jika pelaporan melalui HP/Mobile sedang terkendala, laporan bisa dilakukan lewat web:

  1. Klik menu Input Defect.
  2. Isi formulir secara teliti:
    • Waktu: Otomatis terisi (atau sesuaikan).
    • Jenis Assy: Pilih Final Assy atau Pre Assy.
    • Line / Conveyor: Pilih lokasi terjadinya defect.
    • Jenis Defect & Sub Defect: Pilih klasifikasi cacat yang ditemukan.
    • Quantity (Jumlah): Masukkan angka.
    • Keterangan Tambahan / Area Ditemukan: Isi rinciannya bila perlu.
  3. Klik Simpan / Submit. Laporan Anda akan langsung masuk ke Dashboard Administrator.

C. Edit / Hapus Defect (Koreksi)

Jika baru saja melakukan submit dan ternyata salah ketik:

  1. Dari halaman History di Operator Home.
  2. Cari data tersebut, klik tombol Edit untuk mengubah isian.
  3. Atau klik tombol Delete (Hapus) untuk membatalkan laporan (catatan penghapusan tetap akan terekam di sistem Log Admin).

5. Penyelesaian Masalah (Troubleshooting)

WARNING - Tidak Bisa Login?
Pastikan kapitalisasi huruf pada Nama benar, dan pastikan PIN akurat. Jika lupa PIN, segera hubungi Administrator untuk di-reset.
NOTE - Data di Dashboard Tidak Update (Live)?
Pastikan koneksi jaringan stabil. Jika menggunakan Wi-Fi internal, pastikan perangkat Anda berada di jaringan intranet yang sama.
